# FreeDoom v6 — Quality Intelligence

Версия для демонстрации на хакатоне Freedom Broker. **Официальный оценщик, чек-листы, история оценок, апелляции и формат экспорта JSON 1.0 не изменены.**

## Что нового

### Более презентабельный интерфейс

- Тёмно-зелёная боковая панель, светлая рабочая область, единая дизайн-система.
- Новая главная страница с фактической статистикой загруженных разговоров, 3 языками, 2 новыми возможностями.
- Два основных раздела: **Центр проблем** и **AI Coach**.
- Мобильная адаптация и увеличенные кликабельные области, все старые разделы сохранены.
- Дизайн не требует интернет-доступа, внешних шрифтов и CDN.

### Центр проблем / Root Cause Analysis

- Автоматически группирует типовые слабые места по **закреплённым** оценкам DEV или PROD: консультация, диалог, идентификация, завершение и другие.
- Для каждого паттерна показывает количество и долю среди применимых оценок, обоснование, реальные пронумерованные реплики и ссылку на исходный диалог.
- Рекомендует возможные действия руководителю.
- **Важно:** это гипотезы причин на основе выставленных баллов и их доказательств, а не доказательство корневой причины. Если балл ошибочный, паттерн также может быть ошибочным; поэтому все случаи допускают ручную проверку.
- **Расход Gemini API = 0.** Ничего в базе не изменяет.

### AI Coach

- Откройте «AI Coach» → «↗ Загрузить пример» → «Экспресс-проверка · 0 API». Пример использует реальный диалог `p1-ru-003` (клиент спрашивает о комиссии, черновик отвечает только про название тарифа).
- **Экспресс-проверка**: ограниченные прозрачные правила для проверки явных рисков. Она не использует Gemini и не делает вид, что решает все вопросы качества.
- **Анализ с Gemini**: после галочки согласия на передачу выбранной переписки и черновика внешней модели даёт объяснение, замечания и улучшенный вариант ответа. Для этого нужен действующий `GEMINI_API_KEY` и доступная ключу модель.
- Не отправляет сообщения клиентам, не сохраняет черновики в базе и **не меняет официальные оценки**.
- Не используйте рекомендации без проверки фактов, тарифов и регламентов компании.

## Установка обновления поверх текущей v5 на Mac

1. Остановите сервер: `Ctrl+C`.
2. Создайте резервную копию текущей папки `cqa 3`, особенно `.env` и `data/cqa.sqlite` (если база существует).
3. Откройте терминал:

   ```bash
   cd ~/Downloads/"cqa 3"
   unzip -o ~/Downloads/FreeDoom_CQA_AI_COACH_ROOT_CAUSE_PATCH.zip -d .
   python3 start.py
   ```

4. Откройте http://127.0.0.1:8000 и обновите страницу `Cmd+Shift+R`.

Патч содержит только изменённые и новые исходники. **В нём нет `.env`, SQLite-базы, данных диалогов и сохранённых оценок.**

## Если устанавливаете полную v6 с нуля

```bash
cd cqa
python3 -m pip install -r requirements.txt
cp .env.example .env
# Укажите свой Gemini API-ключ в .env
python3 start.py
```

Полный архив содержит 65 DEV-диалогов и их исторические оценки. Демо новых функций можно показывать без Gemini, полноценный AI Coach с генерацией рекомендаций требует ключ.

## Новые API

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/insights/root-causes?group_id=DEV` | Паттерны по сохранённым оценкам, без расходов API |
| POST | `/api/coach/analyze` | Проверка черновика, `mode=local` или `mode=ai` |

Пример запроса локальной проверки:

```json
{
  "conversation_id": "p1-ru-003",
  "draft": "Название тарифа смотрите там же. Хорошего дня!",
  "mode": "local"
}
```

Для запроса к Gemini дополнительно передаётся `"mode":"ai"` и `"acknowledged_external":true` после осознанного согласия пользователя.
